Change the library passphrase

Runs entirely in your browser — the passphrases are never sent anywhere. It produces a new blob.json you then upload to the site (step-by-step appears after it downloads).

  1. Go to the library folder on GitHub.
  2. Click Add file → Upload files, drag in the downloaded blob.json, and commit. It replaces the old one.
  3. Wait a minute, then unlock the library with the new passphrase.
